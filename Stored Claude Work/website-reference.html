How to Request Section Height Changes

Height is controlled by padding (space above and below the content) — not a fixed height. Just describe how it feels and Claude handles the rest.

MethodExample
Relative terms"Make the Hero taller" · "Shrink the Testimonials section" · "The Process feels cramped, give it more breathing room"
Comparison terms"Make Pricing about half the height it is now" · "FAQ should be similar height to Contact"
T-shirt sizing"Make the Hero XL" · "Testimonials should be S" · sizes: XS · S · M · L · XL
